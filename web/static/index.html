How the liveness check works

Four independent signals, chosen so that defeating one does not help defeat the next.

1

Surface texture

Skin has fine irregular micro-texture. Printing replaces it with ink dots; a screen replaces it with a pixel grid and adds moiré. The system measures local binary patterns, the radial frequency spectrum, and colour and specular statistics, then classifies the surface.

Beaten by: a very high quality print, or a mask made of skin-like material.

2

Blink

Eye aspect ratio and MediaPipe blink activations are tracked across the sequence. A blink counts only if the eye closes and reopens within 70–500 ms — the physiological range. Faster is tracking noise; slower is a squint or something moved across the eyes.

Beaten by: a video replay, which contains real blinks.

3

Parallax under motion

This is the one that does the real work. Rotating a flat sheet in front of a camera is exactly a homography. So the system fits the best homography between frames: if it fits, the thing that turned was flat. It also checks that the misfit tracks landmark depth — real parallax moves the nose more than the cheek.

Beaten by: a cooperative victim, or a real 3-D mask.

4

Depth — honestly unavailable

With a real depth sensor this is the strongest signal there is. This machine has none, so the system says so and refuses to substitute something weaker. The obvious shortcut — fitting a plane to MediaPipe's inferred z — was implemented, measured at Cohen's d = 0.30, and given zero weight. It does not work.

Status: reported for transparency, never counted as evidence.
